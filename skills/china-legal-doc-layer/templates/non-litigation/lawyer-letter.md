# 律师函/催告函/通知函模板（lawyer letter）

## 定位

这是非诉函件的通用模板，适用于：
- 律师函
- 催款函
- 催告函
- 履约通知函
- 违约通知函
- 解除通知函

它的目标不是全面展开复杂法律论证，而是：
- 清楚陈述事实
- 明确表达立场
- 提出正式要求
- 保留后续权利

## 生成前必查字段

最低应掌握：
1. 发函方与收函方身份
2. 发函目的
3. 核心事实
4. 要求事项
5. 履行期限
6. 后续保留权利

## 建议输入模板

```text
【发函方】
...

【收函方】
...

【函件类型】
律师函 / 催款函 / 履约通知 / 解除通知

【事实背景】
...

【我方立场】
...

【具体要求】
1. ...
2. ...

【期限要求】
...

【后续措施】
如不履行，将...

【输出等级】
工作底稿 / 审稿版 / 拟正式版
```

## 标准输出结构

1. 标题
2. 发函背景
3. 核心事实陈述
4. 法律评价或责任判断
5. 我方正式要求
6. 履行期限与后果提示
7. 保留权利
8. 落款

## 写作规则

### 事实陈述
- 尽量客观、简洁
- 不夸张，不添加无法证实的指控

### 法律评价
- 只做与要求事项直接相关的必要评价
- 不要写成长篇法律意见书

### 要求事项
- 要具体、可执行
- 最好分项编号

### 后果提示
- 可以表达将依法采取进一步措施
- 不做超出事实和法律基础的威胁性表述

## 风险控制
遇到下列情况，优先输出审稿版而非拟正式版：
- 事实争议很大
- 侵权/违约认定基础不足
- 送达对象信息不清
- 后续措施尚未确定

## 推荐收尾提醒
- 本函草稿基于现有事实整理，正式发送前请复核主体信息、事实依据、送达方式及具体法律后果表述。
