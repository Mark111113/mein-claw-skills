# 答辩状模板（answer）

## 定位

这是民商事案件通用答辩状模板，用于在收到对方起诉或请求后，系统整理我方回应结构。

复杂争议、程序抗辩与实体抗辩交织时，应先对接 `china-lawyer-analyst` 获取：
- 原告诉请拆解
- 我方抗辩点
- 证据支撑与缺口
- 程序性问题
- 风险提示

## 适用场景

- 民商事一审答辩
- 对起诉状逐项回应
- 补充答辩意见的基础版本
- 仲裁答辩书的通用底稿（需视仲裁规则调整格式）

## 生成前必查字段

最低应掌握：
1. 原告诉请或对方核心主张
2. 我方基本立场
3. 主要抗辩点
4. 我方已有证据
5. 案件当前程序阶段

## 建议输入模板

```text
【我方信息】
...

【对方信息】
...

【对方诉请/主张】
1. ...
2. ...

【我方立场】
同意/不同意哪些部分

【核心抗辩理由】
1. ...
2. ...

【我方证据】
1. ...
2. ...

【程序性问题】
如管辖、时效、前置程序、举证责任等

【输出等级】
工作底稿 / 审稿版 / 拟正式版
```

## 标准输出结构

### 1. 标题
`民事答辩状`

### 2. 当事人信息
- 答辩人
- 被答辩人

### 3. 答辩请求
要求：
- 先概括我方希望法院如何处理
- 可包括驳回全部/部分诉请、诉讼费用承担等

### 4. 答辩事实与理由
建议拆成：
1. 对案件背景的基本说明
2. 对原告诉请的总体回应
3. 分项抗辩理由
4. 程序性异议（如有）
5. 对证据与损失主张的回应

### 5. 证据与依据
- 列出我方主要证据
- 必要时对应每一项抗辩点

### 6. 此致
`此致  [待补：受理法院名称]`

### 7. 落款
- 答辩人
- 日期

### 8. 待补清单（如有）

## 写作规则

### 答辩请求
- 先写裁判目标，再写理由
- 不要把全部分析塞进“请求”里

### 抗辩展开
- 建议按“主张—事实—证据—依据”的顺序写
- 能逐项对应原告诉请时，优先逐项回应
- 区分实体抗辩与程序抗辩

### 风险控制
遇到下列情况，优先输出工作底稿：
- 对方起诉材料不全
- 我方抗辩点尚未成型
- 关键证据尚未整理
- 涉及时效、管辖、前置程序但尚未核实

## 推荐收尾提醒

- 本稿基于现有材料形成答辩结构，正式提交前请复核程序期限、法院信息、证据编号及具体抗辩口径。
