# 起诉状模板（complaint）

## 定位

这是民商事案件通用起诉状模板，优先用于：
- 工作底稿
- 审稿版
- 信息较全时的拟正式版

复杂案件不要直接靠模板硬写，应先对接 `china-lawyer-analyst` 获取：
- 案型识别
- 请求权基础
- 争议焦点
- 证据清单与缺口
- 风险提示

## 适用场景

- 合同纠纷
- 民间借贷纠纷
- 劳动争议（需注意仲裁前置）
- 一般侵权纠纷
- 公司类常规争议（事实较清楚时）

## 生成前必查字段

参考：
- `schemas/party-fields.md`
- `schemas/evidence-fields.md`
- `schemas/procedure-fields.md`

最低应掌握：
1. 原告、被告基本身份
2. 诉讼请求
3. 核心事实时间线
4. 证据目录基础
5. 管辖法院或足以判断管辖的连接点

## 建议输入模板

```text
【原告信息】
...

【被告信息】
...

【案由/纠纷类型】
...

【诉讼请求】
1. ...
2. ...

【事实经过】
按时间顺序描述

【现有证据】
1. ...
2. ...

【管辖相关信息】
被告住所地 / 合同履行地 / 约定管辖等

【输出等级】
工作底稿 / 审稿版 / 拟正式版
```

## 标准输出结构

### 1. 标题
`民事起诉状`

### 2. 当事人信息
- 原告
- 被告
- 第三人（如有）

### 3. 诉讼请求
要求：
- 分项列示
- 具体明确
- 尽量可执行
- 金额、利息、违约金、诉讼费用承担等尽量写清

### 4. 事实与理由
建议按以下顺序组织：
1. 双方关系/交易背景
2. 关键合同或事实发生经过
3. 对方违约/侵权/拒不履行的具体表现
4. 我方损失或应获给付
5. 提起本案诉讼的理由

### 5. 证据和证据来源
- 可先列基础证据目录
- 每项证据尽量对应证明事项

### 6. 此致
`此致  [待补：受理法院名称]`

### 7. 落款
- 具状人
- 日期

### 8. 待补清单（如有）
统一集中列示，不要散落在正文里。

## 写作规则

### 诉讼请求
- 不要把事实写进请求项
- 不要把法理分析写得过多
- 请求项要能直接被法院理解和审理

### 事实与理由
- 以事实为主，法律评价适度嵌入
- 按时间线 + 争议点展开
- 避免情绪化表达

### 法律依据
- 正文中无需大段堆砌法条
- 若引用，优先点明关键依据，不要制造“法条清单感”

### 风险控制
遇到下列情况，降低到工作底稿或审稿版：
- 管辖不明确
- 仲裁前置/劳动仲裁前置未厘清
- 诉请金额和计算口径不清
- 关键证据明显缺失
- 当事人主体信息严重不全

## 推荐收尾提醒

若为工作底稿或审稿版，可附：
- 本稿基于现有材料整理，正式提交前请复核主体信息、管辖依据、诉请口径及证据目录。
