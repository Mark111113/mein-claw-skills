# 当事人字段（party fields）

本文件定义文书层常见的当事人信息字段。

## 个人主体字段
- 姓名
- 性别（如文书需要）
- 出生年月/身份证号（按需要）
- 民族（仅在确有需要时）
- 住址
- 联系方式
- 委托诉讼代理人/律师信息（如有）

## 法人/组织主体字段
- 名称
- 统一社会信用代码
- 住所地
- 法定代表人/负责人
- 职务
- 联系方式
- 委托诉讼代理人/律师信息（如有）

## 角色字段
根据文书类型切换角色：
- 原告 / 被告
- 申请人 / 被申请人
- 上诉人 / 被上诉人
- 申诉人 / 被申诉人
- 发函方 / 收函方
- 委托方 / 相对方

## 可缺省与不可缺省
### 一般不可缺省
- 主体名称/姓名
- 主体角色

### 视文书等级决定是否可缺省
- 身份证号/统一社会信用代码
- 联系方式
- 详细地址

## 占位符示例
- `[待补：原告统一社会信用代码]`
- `[待补：被告送达地址]`
- `[待补：委托诉讼代理人信息]`

## 使用原则
- 工作底稿可以保留占位
- 审稿版应尽量补足
- 拟正式版中，核心当事人身份字段原则上不应缺失
