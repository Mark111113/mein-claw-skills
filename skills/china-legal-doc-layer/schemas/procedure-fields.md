# 程序字段（procedure fields）

本文件定义与程序性文书和诉讼阶段相关的字段。

## 基础程序字段
- 当前阶段：起诉前 / 一审 / 二审 / 再审 / 执行 / 仲裁
- 受理机关：法院 / 仲裁机构 / 对方主体 / 行政机关（按场景）
- 案号（如已有）
- 管辖法院/管辖连接点
- 程序目标（起诉、答辩、申请保全、申请调查取证等）

## 起诉/答辩常见程序字段
- 是否已立案
- 是否已收到起诉材料
- 开庭/答辩期限信息
- 是否涉及保全/鉴定/程序异议

## 程序申请类常见字段
- 申请事项
- 申请理由
- 紧迫性/必要性
- 法律依据候选
- 支持申请的证据

## 管辖与期间字段
- 被告住所地
- 合同签订地
- 合同履行地
- 侵权行为地/结果地
- 诉讼时效相关节点
- 履行期限/催告期限

## 占位符示例
- `[待补：案号]`
- `[待补：受理法院名称]`
- `[待补：开庭日期]`
- `[待补：支持保全必要性的证据]`

## 使用原则
- 诉讼文书要区分实体争议与程序争议
- 涉及具体期间、送达、管辖的内容，正式使用前应再次核验
