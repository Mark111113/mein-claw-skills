# 简式法律意见书示例骨架

> 用于展示 `legal-opinion-short.md` 的推荐成稿结构。示例仅为结构参考。

## 示例场景
客户咨询：在股权转让谈判中，目标公司存在历史用工不规范问题，交易完成后买方是否可能承担相应风险。

## 示例输出

```text
关于目标公司历史用工不规范风险的简式法律意见

一、问题摘要
贵方拟受让目标公司股权，现希望了解：若目标公司在交易完成前存在未签劳动合同、未依法缴纳社保等历史用工不规范情形，受让完成后贵方是否可能因此承担相应法律风险。

二、基本事实与分析前提
根据贵方目前提供的信息：
1. 目标公司存在部分员工未签书面劳动合同的情形；
2. 目标公司可能存在未足额缴纳社会保险的情况；
3. 目前尚未完成专项劳动合规尽调。

本意见基于上述已知事实及现阶段材料形成，若后续尽调发现新事实，本意见结论可能相应调整。

三、法律分析
（一）关于股权转让后主体责任的基本判断
股权转让通常不导致公司主体变更。原则上，历史用工责任仍由公司作为用人单位承担。但在交易完成后，作为股东或控制方，贵方将间接承受该类历史风险对公司经营、财务和合规状态造成的影响。

（二）关于主要风险表现
历史用工不规范风险可能表现为：
1. 员工主张未签书面劳动合同二倍工资；
2. 员工或监管部门追索社会保险差额；
3. 因历史劳动关系处理不规范引发劳动仲裁或诉讼。

（三）关于交易层面的应对建议
建议贵方在交易文件中重点关注并设置：
1. 劳动合规专项陈述与保证；
2. 历史劳动风险的赔偿与追偿条款；
3. 交割前整改义务；
4. 必要时设置价款调整或风险准备机制。

四、结论意见
基于现有信息，股权转让本身通常不改变目标公司对既有劳动责任的承担主体，但贵方在交易完成后可能通过公司层面间接承受历史用工不规范带来的经济与合规风险。因此，建议将劳动合规问题作为交易审查重点，并在交易文件中设置充分的风险分配机制。

五、风险与保留说明
本意见基于当前已知事实形成，未替代完整法律尽职调查，也未覆盖全部行业监管规则。正式决策前，建议结合专项尽调结果及最新法源进一步复核。
```

## 结构点评
- 简式意见书要先说问题，再说前提，再分析，再下结论
- “风险与保留说明”不能省
