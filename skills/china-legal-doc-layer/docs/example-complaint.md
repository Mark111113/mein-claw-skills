# 起诉状示例骨架

> 用于展示 `complaint.md` 的推荐成稿结构。示例仅为结构参考，不代表真实案件结论。

## 示例场景
买卖合同尾款纠纷

## 示例输出

```text
民事起诉状

原告：甲公司，住所地：[待补：详细地址]。
法定代表人：[待补：姓名]，职务：[待补：职务]。

被告：乙公司，住所地：[待补：详细地址]。
法定代表人：[待补：姓名]，职务：[待补：职务]。

诉讼请求：
1. 请求判令被告向原告支付货款人民币 800,000 元；
2. 请求判令被告支付逾期付款损失（以 800,000 元为基数，自 [待补：起算日期] 起计算至实际清偿之日止，按 [待补：计算标准] 计算）；
3. 请求判令本案诉讼费用由被告承担。

事实与理由：
原、被告于 [待补：合同签订日期] 签订《设备买卖合同》，约定由原告向被告提供 [待补：设备名称]，合同总价为 [待补：合同总价] 元。合同签订后，原告已按约完成供货，并由被告于 [待补：签收日期] 签收确认。

根据合同约定，被告应于 [待补：付款日期] 前向原告支付尾款人民币 800,000 元。但截至起诉之日，被告仍未支付该尾款。原告曾于 [待补：催款日期] 通过 [待补：催告方式] 向被告催告付款，但被告至今未履行付款义务。

原告认为，双方之间买卖合同关系合法有效，原告已履行主要合同义务，被告未按约支付尾款，已构成违约，应依法承担相应民事责任。为维护原告合法权益，特向贵院提起诉讼，请依法判如所请。

证据和证据来源：
1. 《设备买卖合同》1 份，证明双方存在买卖合同关系及付款约定；
2. 送货单/签收单 1 组，证明原告已履行交付义务；
3. 催款函/微信催款记录 1 组，证明原告已催告付款；
4. 对账材料 [待补：如有]，证明尾款金额及欠付事实。

此致
[待补：受理法院名称]

具状人：甲公司
法定代表人/授权代理人：[待补]
[待补：日期]
```

## 结构点评
- 诉讼请求应独立编号
- 事实与理由按“合同—履行—违约—催告—起诉”顺序组织
- 证据目录要对应请求项和事实主线
