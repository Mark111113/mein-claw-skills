# 律师函示例骨架

> 用于展示 `lawyer-letter.md` 的推荐成稿结构。示例仅为结构参考。

## 示例场景
针对拖欠服务费发送催款律师函。

## 示例输出

```text
律师函

致：乙公司

受甲公司委托，现就贵司拖欠服务费一事，郑重函告如下：

一、基本事实
甲公司与贵司于 [待补：签约日期] 签订《服务合同》，约定甲公司向贵司提供 [待补：服务内容]，贵司应于 [待补：付款期限] 前支付服务费人民币 [待补：金额] 元。甲公司已依约完成相关服务，并于 [待补：履行时间] 向贵司提交成果/完成交付。

二、履行情况及目前争议
截至本函出具之日，贵司仍未向甲公司支付上述服务费。甲公司此前已通过 [待补：催告方式] 多次催告付款，但贵司至今未予履行。

三、我方意见
根据双方合同约定及现有履行情况，贵司应及时向甲公司支付前述欠付服务费。贵司长期拖延付款的行为，已对甲公司合法权益造成不利影响。

四、正式要求
请贵司在收到本函后 [待补：期限，如 5 日/7 日] 内：
1. 向甲公司支付欠付服务费人民币 [待补：金额] 元；
2. 如对付款金额或履行情况存在异议，请于上述期限内书面说明并提供依据。

五、保留权利
如贵司未在前述期限内妥善履行或作出合理答复，甲公司将保留依法采取进一步措施的权利，包括但不限于提起诉讼、主张违约责任及相关损失。

特此函告。

[待补：律师事务所名称]
律师：[待补：姓名]
[待补：日期]
```

## 结构点评
- 律师函不宜写成长篇法律意见书
- 要求事项与期限必须明确
- “保留权利”是关键收束段落
