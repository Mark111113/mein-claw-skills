# 文书层分类树（taxonomy）

本文件用于给 `china-legal-doc-layer` 提供**文书类型路由依据**。它是路由参考，不是每次生成时都要全文加载的主提示。

## 一级分类

### A. 诉讼启动类文书
- 起诉状
- 仲裁申请书
- 强制执行申请书
- 撤诉申请
- 变更/追加诉请申请

### B. 被动应对类文书
- 答辩状
- 补充答辩意见
- 反诉状
- 仲裁答辩书

### C. 代理意见类文书
- 一审代理词
- 二审代理词
- 再审代理意见
- 补充代理词
- 质证意见
- 庭后补充意见

### D. 程序申请类文书
- 管辖权异议申请书
- 财产保全申请书
- 行为保全申请书
- 证据保全申请书
- 调查取证申请书
- 司法鉴定申请书
- 延期审理申请书
- 回避申请书
- 中止/恢复审理申请书
- 保全复议意见

### E. 上诉与救济类文书
- 上诉状
- 上诉补充理由
- 再审申请书
- 再审补充意见
- 检察监督申请书

### F. 非诉函件类文书
- 律师函
- 催告函
- 催款函
- 履约通知函
- 违约通知函
- 解除通知函
- 停止侵权函
- 保留追责函

### G. 法律分析与顾问类文书
- 简式法律意见书
- 正式法律意见书
- 专项法律分析报告
- 风险评估报告
- 合同审查意见书
- 尽职调查报告

### H. 合同与交易类文书
- 买卖合同
- 服务合同
- 保密协议
- 股权转让协议
- 借款协议
- 和解协议
- 红线审查意见
- 条款替换稿

## 文书层首批范围（MVP）

第一版优先支持：
1. 起诉状
2. 答辩状
3. 通用代理意见/补充代理词
4. 通用程序申请类文书
5. 律师函/催告函/通知函
6. 简式法律意见书
7. 合同审查意见书

## 分类使用原则

- 用户明确说“起诉”“上诉”“申请执行” → 优先路由到诉讼启动/救济类
- 用户明确说“答辩”“回应对方诉求” → 路由到被动应对类
- 用户明确说“代理词”“补充意见”“质证意见” → 路由到代理意见类
- 用户明确说“申请保全”“申请调查取证”“申请回避” → 路由到程序申请类
- 用户明确说“发函”“催款”“通知解除” → 路由到非诉函件类
- 用户明确说“出意见书”“给个法律分析结论” → 路由到法律分析与顾问类
- 用户明确说“起草合同”“修合同”“红线审查” → 路由到合同与交易类

## 扩展规则

新增模板时：
- 先确定其一级分类
- 再判断是否已有可复用的通用模板
- 若没有，再新增专属模板文件
