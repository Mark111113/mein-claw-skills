# 答辩状示例骨架

> 用于展示 `answer.md` 的推荐成稿结构。示例仅为结构参考。

## 示例场景
买卖合同尾款纠纷中，被告以质量问题和结算条件未成就进行答辩。

## 示例输出

```text
民事答辩状

答辩人：乙公司，住所地：[待补：详细地址]。
法定代表人：[待补：姓名]，职务：[待补：职务]。

被答辩人：甲公司，住所地：[待补：详细地址]。
法定代表人：[待补：姓名]，职务：[待补：职务]。

答辩请求：
1. 请求依法驳回原告关于支付全部尾款的诉讼请求；
2. 请求依法驳回原告关于逾期付款损失的主张；
3. 请求本案诉讼费用由原告承担。

答辩事实与理由：
一、原告主张的付款条件尚未完全成就。
根据双方合同约定，被告支付尾款的前提之一为 [待补：结算/验收条件] 完成。但截至目前，原告尚未提交完整的 [待补：验收文件/结算材料]，故原告关于“尾款已到期应付”的主张依据不足。

二、涉案设备存在质量瑕疵，原告应先行承担相应责任。
被告在使用涉案设备过程中发现 [待补：质量问题描述]，并已于 [待补：通知时间] 向原告提出。原告在该问题解决前即要求支付全部尾款，缺乏合同和事实基础。

三、原告主张逾期付款损失缺乏前提条件。
在付款条件未成就、质量问题尚未解决的情况下，被告未支付尾款并不当然构成违约，原告关于逾期付款损失的请求不应得到支持。

证据与依据：
1. 《设备买卖合同》1 份，证明尾款支付条件约定；
2. 质量问题通知记录 1 组，证明被告已及时反馈设备问题；
3. 验收/结算材料 [待补]，证明付款条件尚未完全成就；
4. 维修沟通记录 [待补]，证明质量问题持续存在。

此致
[待补：受理法院名称]

答辩人：乙公司
法定代表人/授权代理人：[待补]
[待补：日期]
```

## 结构点评
- 先写答辩请求，再分项展开抗辩理由
- 抗辩理由建议与原告诉请形成对应关系
- 若存在程序异议，可单列一节置于前部或后部
