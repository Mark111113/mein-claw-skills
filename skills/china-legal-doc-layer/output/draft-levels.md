# 输出等级说明

本文件定义文书输出的三种等级。

## L1：工作底稿
适用：
- 事实不完全
- 需要内部讨论
- 需要律师继续补充

特点：
- 允许占位符
- 可附加较多注释
- 强调结构完整和问题暴露

## L2：审稿版
适用：
- 文书结构基本成型
- 事实较清楚
- 需给律师/法务审阅

特点：
- 结构完整
- 语言较稳
- 注释减少
- 待补项集中列示

## L3：拟正式版
适用：
- 事实较完整
- 当事人信息清楚
- 证据与目标明确
- 法律风险可控

特点：
- 接近正式文书表达
- 保持专业语气
- 仍应附人工复核提醒

## 默认策略

- 默认优先输出 L1 或 L2
- 只有用户明确要求正式稿且信息完整时，才输出 L3
